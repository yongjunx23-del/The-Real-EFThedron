Compact-energy components for the exact 261.3814-degree and 268-degree witnesses

Scope
-----
These are only the V/p < -1 components on every even spin ell >= 42 and
4 < mu <= 49. They are not complete directional support bounds by themselves.
The separate finite head, UV coercivity and real-norm integrals must be bound
to the same witness/objective and assembled by the root campaign verifier.

Proof adaptation
----------------
The new files copy the already reviewed angle259 compact method without
changing its inequalities. Only witness, objective, source paths, maximum
finite spin and associated dependency/review names are changed. The analytic
all-powers Jensen envelope checks every shifted crossing coefficient by exact
Bernstein bounds. The nonnegative powers of (k-10)_+ are retained, their
negative constant is dropped, and the k<10 cap is bounded separately. The
low-energy spin derivative is checked negative. Physical-energy positive
Legendre denominator monomials use the previously reviewed monotonic ratio.
Both 400-bit and 512-bit analytic runs choose identical exact rectangles and
spin cutoffs. Analytic cutoff selection is finite; the accepted inequalities
on each selected rectangle apply to every larger spin.

The residual finite-spin proof uses exact source moments, N=256 geometric
remainders and removable-pole/PV formulas. Every accepted exact energy cell
is computed at 512 bits and replayed at 640 bits. The existing source-geometry
partition seed is used only as an initial partition; no value or inequality
from its different witness is reused.

Environment and preservation
----------------------------
Use the root reproducibility archive's pinned Python/dependency environment.
The files import python-flint, NumPy, SciPy and SymPy as supplied by that
environment. In PowerShell, BEFORE starting any Python process:

$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
$env:PYTHONPATH='tmp/certification_deps'

Run from the repository root. In commands below, python means that pinned
interpreter. Existing proof inputs must remain immutable. For fresh rebuilds,
use a disposable copy of the archive and an empty corresponding NEW campaign
output tree. Never remove or overwrite the canonical archived outputs. The
moment builder intentionally refuses to overwrite completed tables.

Source prerequisites
--------------------
The frozen source caches are prepared by the separately owned scripts:
python research/boundary_length_20261007/tail/prepare_angle261p3814.py
python research/boundary_length_20261007/tail/prepare_angle268.py

Their prepared_components.json binds the witness, source data, canonical
parameters and exact Roy/crossing prerequisites. Reusing the archived caches
and validating their hashes is a frozen-input replay, not a from-scratch
independent source reconstruction. A fresh source build must retain the
correct prerequisite audit files and must subsequently use newly matching
provenance throughout its own complete packet.

Finite proof and replay
-----------------------
python research/boundary_length_20261007/compact/run_piecewise261p3814.py
python research/boundary_length_20261007/compact/run_piecewise268.py

Each launcher uses TWO thread-limited concurrent workers, so running both
uses at most FOUR finite proof/replay worker processes in total. It waits for
the two moment manifests, checks independent floating fields at spins42 and
the maximum finite spin, then runs each finite producer and its higher-
precision replay in sequence. The independent numerical comparison is a
diagnostic only; it is not used to accept a continuum inequality.

Each exact subprocess command, exit code and duration is retained in
compact/angleNAME/commands.jsonl. Standard output/error is saved in
point_check.log and piece_*_512.log / piece_*_640.log. JSON proof packets
also retain wall times, exact partitions and dependency hashes. Summed
process times are not the elapsed time of parallel execution.

To reproduce a single rectangle directly (example):
python research/boundary_length_20261007/compact/certify_finite268_slice.py --mu-min 42 --mu-max 49 --lmax 60 --bits 512 --out NEW_PRODUCER.json
python research/boundary_length_20261007/compact/replay_piecewise268.py --input NEW_PRODUCER.json --out NEW_REPLAY.json --bits 640 --jobs 1

Complete compact packet
-----------------------
After the independent adaptation review and moment audit are present:
python research/boundary_length_20261007/compact/assemble_angle261p3814.py
python research/boundary_length_20261007/compact/assemble_angle268.py

The expected packet path is compact/angleNAME/complete_compact_coercivity.json,
status PASS_COMPLETE_COMPACT_COERCIVITY, kappa_exact 1, minimum_even_spin42,
mu_domain_exact [4,49], lower_energy_endpoint_open true. The hash manifest
binds both precisions, finite cells, analytic rectangles, source tables,
source audits and reviewed formulas. Preserve every path named in it.

Arithmetic replay is internal verification sharing mathematical code. It is
not formal proof-assistant checking, external review or an independent
implementation of the entire scattering-amplitude argument.
